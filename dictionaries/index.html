Word lists for Curmudgeon Keyboard · files and licences on GitHub

Download the file for your language, then open it from your downloads with Curmudgeon Keyboard (or add it in the keyboard's settings for that language). The lists also work in HeliBoard and other keyboards that read Android .dict files.
